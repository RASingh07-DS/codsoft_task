# CodSoft Internship Tasks

This repository contains the Python projects I completed during my CodSoft Internship. The projects are based on basic Python programming and focus on building simple command-line applications.

## Tasks Completed

### Task 1 – To-Do List

The To-Do List application helps users manage their tasks from the command line. Users can add new tasks, view their tasks, update them, mark tasks as completed, and delete tasks when they are no longer needed.

**File:** `Task-1-To-Do-List/todo.py`

---

### Task 2 – Simple Calculator

The Calculator is a simple command-line program that performs basic arithmetic operations. The user enters two numbers and selects an operation to get the calculated result.

**Operations included:**

* Addition
* Subtraction
* Multiplication
* Division

**File:** `Task-2-Calculator/calculator.py`

---

### Task 3 – Contact Book

The Contact Book is a command-line application for managing contact information. It allows users to add contacts and store their name, phone number, email, and address. Contacts can also be viewed, searched, updated, or deleted.

**File:** `Task-3-Contact-Book/contact_book.py`

---

## How to Run

Make sure Python is installed on your system, then run any project using the corresponding command:

```bash

```


